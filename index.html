About Me

I am Henry Martin, a security researcher working on Linux kernel security, vulnerability research and blockchain security. I hunt bugs in the upstream kernel, reproduce real-world exploits, and write down what I learn.

To date I have contributed 32 upstream fixes to the Linux kernel, 22 of which were assigned CVEs, covering UAF, OOB and NULL-deref bugs across networking, tracing, wireless and driver subsystems.

Research Interests

🛡️ Kernel Security

Bug hunting in the upstream Linux kernel, Android GPU driver exploitation (Mali CVE-2023-48409), and kernel heap techniques (Cross-Cache, Dirty Pagetable, KSMA).

⛓️ Blockchain Security

Smart contract auditing and on-chain attack analysis (Solidity, Ethereum challenges).

🔍 Program Analysis & Fuzzing

Static analysis (NJU Software Analysis, CodeQL), symbolic execution (KLEE, angr) and fuzzing (AFL, UBfuzz).
